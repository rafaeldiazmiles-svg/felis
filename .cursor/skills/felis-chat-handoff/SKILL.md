# Handoff

Write or update one file: `TODO/notasRafa/LoadPrefabByBounds.HANDOFF.txt`, or a new `TODO/notasRafa/<topic>.HANDOFF.txt` if the topic is not streaming.

Keep it under 20 lines:

- Topic and the one file in scope
- Do not edit until asked
- What is already true
- The single pending ask
- No queries unless authorized
- Say what you will create before creating it
- Notes live in `TODO/notasRafa/`

## Never

- Never paste long source into the handoff.
- Never start the next task in the same turn as the handoff.
